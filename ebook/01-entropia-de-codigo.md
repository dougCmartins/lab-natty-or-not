**Bancada Viva — cinco hábitos para programar com IA**

# Entropia de código

Desordem no código não fica parada. Ela cresce. Cada nome frouxo, cada teste que falta, cada dependência que ninguém pediu empurra o projeto um pouco mais para o lado bagunçado. Isso é entropia: a tendência de o trabalho se desorganizar quando ninguém gasta energia para contê-la.

A IA generativa acelera os dois lados. Ela escreve rápido. Também espalha rápido. Um rascunho aceito sem leitura vira a base do próximo pedido. O modelo aprende o seu silêncio. Se você cola o bloco inteiro e segue em frente, a desordem entra no repositório com a sua assinatura.

O hábito é simples. Antes de pedir código novo, peça o diagnóstico do que já está solto. Energia pequena, gasta cedo, segura o resto.

Na bancada: leia a lista. Corrija o que cabe numa sentada. Só então peça a próxima mudança.

## Prompt para colar

```text
Olhe este código como um revisor curto. Não escreva código novo.
Liste só o que está frouxo: nomes pouco claros, testes que faltam,
dependências que não foram pedidas e trechos que ninguém vai entender
daqui a um mês. Uma linha por item. Espere eu escolher o que corrigir.
```

Uma mão para no meio e separa um pequeno monte antes de acrescentar qualquer peça nova. Sem letras, sem logos, sem marca d'água, sem texto legível. Retrato 3:4. Evite rosto fotográfico de pessoa real e evite tela de computador com código.
