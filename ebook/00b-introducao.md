**Bancada Viva — cinco hábitos para programar com IA**

# Introdução

Este capítulo cabe numa sentada. Ele não pede que a IA programe no seu lugar. Pede que você conduza o pedido para o código não apodrecer.

São cinco hábitos. Cada um cabe numa página. No fim de cada página há um prompt para colar no chat. Use esse prompt no próximo diff.

A desordem cresce quando o rascunho entra sem leitura. Um trecho que já roda vale mais do que o sistema inteiro desenhado de uma vez. Uma regra mora num lugar só. O primeiro defeito pequeno autoriza o próximo. Um fio fino, que executa de verdade, mostra onde ajustar a mira.

As ideias de fundo vêm de Andrew Hunt e David Thomas. O texto é outro. A bancada é a sua.
